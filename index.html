YT Stream Scheduler

YT Stream Scheduler is a personal command-line tool. It schedules its developer's recurring Zwift race livestreams on YouTube from templates: it creates the upcoming live broadcast with the template's title, description, thumbnail and settings, and links it to the developer's stream before each race.

It is used only by its developer, on the developer's own YouTube channel. It is not offered to anyone else.

It uses YouTube API Services.
